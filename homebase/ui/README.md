# J.A.R.V.I.S. Home Base UI

First premium interface layer for J.A.R.V.I.S.

## Stack

- React + Vite
- Tailwind CSS
- Motion for interaction/state animation
- CSS GPU-friendly ambient animation for continuous background motion

## Run

```bash
cd homebase/ui
npm install
npm run dev
```

## Design direction

The UI intentionally avoids a static wallpaper and instead uses layered ambient gradients, subtle grain, glass surfaces, and a continuously breathing core. JARVIS states can later drive the animation intensity and voice visualization.

Animaster is intentionally not included until its exact maintained package/repository is identified.
