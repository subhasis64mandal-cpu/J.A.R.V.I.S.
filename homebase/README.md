# J.A.R.V.I.S. Home Base

Home Base is the repository-controlled control plane for J.A.R.V.I.S. It owns identity, configuration, capability metadata, runtime observability, and the allowlisted command surface.

Current read-only capabilities are system diagnostics, workspace-scoped file inspection, and bounded HTTP(S) retrieval. Computer, browser, and paired-device control remain staged behind explicit policy and adapter contracts.
