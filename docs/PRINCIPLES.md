# J.A.R.V.I.S. engineering principles

1. **Brain proposes; control plane decides.**
2. **Every executable capability is registered and inspectable.**
3. **Read-only capabilities default to bounded inputs and outputs.**
4. **State-changing actions require explicit policy and confirmation where appropriate.**
5. **Home Base owns configuration and observability, not arbitrary execution.**
6. **Device identity is separate from device transport.**
7. **UI state is driven by runtime events, not fake animation alone.**
8. **Optional dependencies are introduced only with a concrete capability and tests.**
